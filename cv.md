# Cosmetic Store E-commerce Platform - CV Bullet Points

## 📁 **Project Summary**
Developed a full-stack e-commerce platform for cosmetic products with multi-environment deployment capabilities using modern web technologies and cloud infrastructure.

---

## 💻 **Tech Stack**

### **Backend Technologies:**
- **Java 21** with **Spring Boot 3.5.3** framework
- **Spring Security** with JWT authentication and OAuth2 integration
- **Spring Data JPA** with MySQL 8.0 database
- **Maven** for dependency management and build automation
- **Thymeleaf** template engine for server-side rendering

### **Frontend Technologies:**
- **React 19.1.1** with functional components and hooks
- **React Router DOM 7.8.0** for client-side routing
- **React Bootstrap 2.10.10** with responsive UI components
- **Axios 1.11.0** for HTTP client requests
- **React Context API** for state management

### **Infrastructure & DevOps:**
- **Docker** containerization with multi-stage builds
- **Docker Compose** for local development with hot reload
- **AWS Cloud** deployment with Terraform IaC
- **GitHub Actions** CI/CD pipelines for automated deployment
- **Nginx** reverse proxy for production environments

### **External Integrations:**
- **Cloudinary** for cloud-based image storage and optimization
- **Firebase** real-time chat messaging system
- **MoMo Payment Gateway** for Vietnamese payment processing
- **Google OAuth2** and **Facebook OAuth2** social login
